First release of DHCP Server for Windows.

Download `DHCPServer.exe` below and double-click it. Nothing else needs to be installed.

- Windows SmartScreen will warn that the app is unrecognised, because it is not signed. Click **More info**, then **Run anyway**.
- In the Setup tab, click **Allow DHCP Server Through Windows Firewall** once. Without it, no device receives an address.

This build has been checked to start on Windows, but has not yet been tested against real devices. Please open an issue if something does not work.
